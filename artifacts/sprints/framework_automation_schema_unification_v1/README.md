# framework_automation_schema_unification_v1

This sprint unifies schema, gate, scoring, feedback, and automation-plan artifacts for the scheduler-driven semi-autonomous discovery framework. It performs no new family experiment, no render/run, no GLM call, and no vulnerability claim.

Key output directories:

- `input/`: completed family inventory
- `schema/`: family, route, mutation/render/analysis, and feedback schemas
- `gates/`: evidence and A-path/GLM gates
- `scheduler/`: scheduler scoring contract
- `automation_plan/`: `auto_scheduler_v1` and `auto_discovery_loop_v1` designs
- `reports/`: roadmap and final sprint report
