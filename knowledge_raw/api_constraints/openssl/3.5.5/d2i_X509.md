# API Constraints: d2i_X509 (OpenSSL 3.5.5)

Source version: `/home/wen/work/clean_sources/openssl-3.5.5`

## API

- API/function name: `d2i_X509`
- Header/manpage: `include/openssl/x509.h`, `doc/man3/d2i_X509.pod`
- Implementation file: generated by `IMPLEMENT_ASN1_FUNCTIONS(X509)` in `crypto/x509/x_x509.c`
- Signature:

```c
X509 *d2i_X509(X509 **a, const unsigned char **pp, long length);
```

## Semantics

- DER-decodes an X.509 certificate from memory.
- On success, advances `*pp` past the consumed DER object.

## Return Value Semantics

- Returns `X509 *` on success.
- Returns `NULL` on ASN.1/X.509 parse failure; error details are in OpenSSL error queue.

## Ownership and Buffer Constraints

- Returned certificate is caller-owned and freed with `X509_free()`.
- Input bytes remain caller-owned.
- Pointer advancement lets harnesses detect whether trailing bytes were consumed or left unconsumed.

## Harness Generation Notes

- Use `const unsigned char *p = der; X509 *x = d2i_X509(NULL, &p, len);`.
- For `MBEDTLS-POC-0017`, feed malformed nested ASN.1 certificate bytes and observe NULL/error queue and pointer movement.

## Vulnerability-Pattern Migration Notes

- Strong candidate for X.509 nested-boundary parser migration.
- Evaluate whether inner malformed substructures are rejected at child bounds rather than accepted or parsed using an outer bound.
